# MCP: Ampliación del acceso al contenido técnico controlado

Descubra cómo el Protocolo de contexto de modelo (MCP) permite que las experiencias con tecnología de IA interactúen de forma segura con AEM Guides mediante solicitudes en lenguaje natural, respetando al mismo tiempo los controles de acceso y permisos de AEM existentes. En esta sesión, explicamos la arquitectura, la configuración, la autenticación y el modelo de seguridad de MCP, mostramos las capacidades admitidas actualmente y exploramos casos de uso prácticos, límites actuales y consideraciones clave. También cubre las consideraciones de implementación para entornos AEM as a Cloud Service y On-Prem/AMS, muestra cómo los clientes con MCP pueden conectarse con AEM Guides y analiza dónde se adapta MCP junto con las capacidades de IA más amplias de Adobe.
