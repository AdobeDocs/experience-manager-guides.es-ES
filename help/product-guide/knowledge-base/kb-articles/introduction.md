# Base de conocimiento de Experience Manager Guides

La Base de conocimiento contiene artículos prácticos basados en escenarios para Experience Manager Guides que abarcan configuraciones comunes, personalizaciones y casos de uso que van más allá de la documentación del producto principal.

| Categoría | Descripción |
|---|---|
| Creación | Sugerencias y técnicas para crear y reutilizar contenido en el editor, incluidas las personalizaciones del editor, la administración de metadatos y la validación de contenido. |
| Marco de extensión de Guides | Aprenda a personalizar la interfaz de usuario de Experience Manager Guides, desde la introducción al marco de trabajo de extensiones hasta la creación de componentes personalizados, widgets y personalizaciones de la aplicación de revisión. |
| Source de datos externos | Directrices para la integración y configuración de conectores de fuentes de datos externas con Experience Manager Guides. |
| Publicación | Prácticas recomendadas para la generación de resultados, incluidas las configuraciones de publicación nativas de PDF, DITA-OT, AEM Sites templates y basadas en microservicios. |
| Flujos de trabajo | Configure y utilice flujos de trabajo de generación posterior para automatizar pasos después de generar la salida. |
| Traducción | Instrucciones sobre cómo mejorar el rendimiento de la traducción y administrar qué contenido se incluye o excluye de la traducción. |
| Casos de uso | Obtenga información acerca de los escenarios reales, como el contenido condicional, el trabajo con claves y las variables de contenido contextual en la salida publicada. |
