# Migrar contenido existente {#id181AGB000Y4}

AEM Guides permite convertir una variedad de documentos estructurados y no estructurados al formato DITA. En este tema se explica cómo cargar el contenido DITA en el repositorio de AEM y cómo convertir el contenido que no es DITA al formato DITA.

>[!TIP]
>
> Consulte la sección *Migración y carga de contenido* de la guía de prácticas recomendadas para conocer las prácticas recomendadas sobre el uso de la migración y la carga de contenido existente.

En la tabla siguiente se describen los distintos métodos de migración disponibles para cargar contenido DITA en Experience Manager Guides. También proporciona instrucciones para migrar contenido no DITA y configurar el patrón de archivos UUID.
